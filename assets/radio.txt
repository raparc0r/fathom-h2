# Fathom's internet radio stations: fathom/radio.txt on the card.
# (This example comes with Fathom as fathom/assets/radio.txt and is used until
# there's a fathom/radio.txt: copy it there to make the list your own.)
#
# One station per line:   Name = stream URL
# Lines starting with # are notes. The order here is the order on the H2.
#
# What's playing comes from the stream itself when the station sends it (most
# Icecast/Shoutcast streams do). For stations that don't, add after the URL
#   | info: radiofrance:N     Radio France's live API, station N (FIP is 7)
#
# A station's logo, shown beside its name, is the address of a PNG or JPEG
# picture, last on the line (Find stations adds it when the directory has one):
#   | icon: https://example.com/logo.png
# Or give the station's own web page, and Fathom takes the icon that page
# names (the one a phone would put on its home screen, or its favicon):
#   | site: https://example.com/
#
# Streams can be MP3, AAC, Ogg FLAC, Ogg Vorbis... over http or https.
